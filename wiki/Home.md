# ⬡ Hex MCTS & MuZero Engine Wiki

Welcome to the official **Hex MCTS & Hybrid PyTorch MuZero Engine** Wiki!

This repository hosts an installable, self-updating Progressive Web Application (PWA) and a high-performance PyTorch deep reinforcement learning backend for the game of Hex.

---

## 📚 Wiki Contents

* **[[Competition]]** — Information, rules, schedules, and entry requirements for the upcoming Hex AI Competition.
* **[[Architecture and Models]]** — In-depth technical breakdown of the dual-mode system (Client-side JS MCTS vs. Hybrid PyTorch Latent MCTS with BPTT).
* **[[Benchmarking Suite]]** — Guide to Wald's Sequential Probability Ratio Test (SPRT) and the Logistic CSE Simulation Parity Benchmark.
* **[[Setup and API Guide]]** — Instructions for local development, WebSocket API streaming, and self-play CLI training.
