⬡ Hex MCTS Demo Overview

An interactive game demonstrating real-time Monte Carlo Tree Search (MCTS) for the classic two-player strategy game Hex.

1. Overview & Purpose

Hex is a connection game played on a rhombus grid of hexagonal cells. The Human (Red) attempts to form an unbroken chain of connected stones from Top to Bottom, while the AI (Blue) attempts to connect Left to Right. In Hex, draws are mathematically impossible.

This web application demonstrates how a pure Monte Carlo Tree Search (MCTS) algorithm discovers winning strategies from scratch in real-time—without any pre-computed opening books, lookup tables, or pre-trained models.

2. User Interface (UI) Components Breakdown

The interface is built with a responsive, dark-mode navy/cyan design theme. On desktop screens, it uses a side-by-side split layout, while on mobile devices it gracefully stacks into a clear vertical layout.

Header Bar & Version Badge

  • Title: ⬡ Hex MCTS displayed in glowing electric cyan text.
  • Version Badge (v2.0): Located next to the main title in a subtle semi-transparent cyan container.
  • Dynamic Subtitle: Displays the active game mode (e.g., Human (Red) vs AI (Blue) · 7×7), updating automatically whenever the board size is changed.

Interactive Hexagonal Board

  • Pointy-Top Hexagonal Grid: Displays the game board in a classic rhombus shape.
  • Dynamic Geometry Scaling: Automatically rescales hex size and centers the grid whether playing on 5×5, 7×7, or 11×11 boards.
  • Colored Goal Borders:
    • Red Edges: Top and Bottom borders are highlighted in warm red (#FF4444).
    • Blue Edges: Left and Right borders are highlighted in electric blue (#4488FF).
  • Interactive Touch & Mouse Support: Permits both desktop mouse clicks and mobile tap gestures to place stones.

Hex Cell Numbering & Live MCTS Heatmap Overlay

  • 1-Based Hex Cell Numbering: Every cell displays its unique cell number (1…N, where N = size²).
    • On Empty Cells: Cell numbers appear in a soft, semi-transparent font.
    • On Occupied Cells: Cell numbers remain visible over placed stones.
  • Real-Time Heatmap Visualization: While the AI thinks:
    • The cell number shifts slightly upward.
    • A cyan visit count displays prominently in the center of the cell, color-coded from dark blue (low visits) to bright electric cyan (high visits).
    • The numbers flash and update live as the MCTS engine explores different paths.

Side Control Panel

A. Status Display Box: Shows real-time turn state and outcome notifications:

  • Your turn — place a Red stone (Normal state)
  • 🔵 Blue AI thinking... (Animated pulse effect while MCTS searches)
  • 🔴 Red wins! (Highlighted in red)
  • 🔵 Blue wins! (Highlighted in blue)

B. Parameter Control Sliders:

  1. Board Size Slider (Range: 5×5 to 11×11, Default: 7×7): Dynamically reconfigures grid dimensions and resets the board.
  2. Thinking Time Slider (Range: 500ms to 5000ms, Default: 1500ms): Sets the time budget allocated for the AI to explore moves per turn.
  3. Exploration Parameter (c) Slider (Range: 0.0 to 5.0, Default: 1.40): Controls the exploration vs. exploitation trade-off in the UCT formula:
    UCT = ( wi / ni ) + c × √( ln Ni / ni )

C. Action Buttons:

  • Restart Game Button: Resets the current board state and starts a fresh game at the chosen board size.
  • 📥 Install App Button: Displays automatically on supporting browsers when the app is installable as a native desktop/mobile application.
