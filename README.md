# Hex Presentation Graphics

Python scripts for generating presentation slide graphics using `matplotlib` and `networkx`.

## Files

| File | Description |
|------|-------------|
| `generate_hex_bg.py` | Abstract fading hexagonal grid background (1920×1080) |
| `generate_explosion.py` | Minimax vs MCTS decision tree comparison (v1) |
| `generate_explosion_v2.py` | Minimax vs MCTS comparison — improved contrast & layout (v2) |

## Generated Images

| Image | Resolution |
|-------|-----------|
| `hex_bg.png` | 1920×1080 RGBA |
| `combinatorial_explosion.png` | 3840×2160 RGBA |
| `combinatorial_explosion_v2.png` | 3840×2160 RGBA |

## Requirements

- Python 3.11+
- `matplotlib`
- `networkx`
- `numpy`
